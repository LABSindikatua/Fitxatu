# Fitxatu
**Ostalaritzako langileentzako ordu-kontagailua.**

Fitxatu aplikazioak Bizkaiko ostalaritzako langileen lan ordu kopurua zenbatzeko eta kontrolatzen laguntzen duen aplikazioa da. Horretarako, geolokalizazioa erabiltzeko aukera ematen du, erregistratutako orduei balio handiago emateko asmoz. Gainera, lan orduren bat erregistratzen ahaztu ezkero, eskuz ere egiteko aukera dago. Horretaz gain, gordetako datu guztiak ikusi ahal izateko parada du erabiltzaileak, sartutako ordu extrak kalkulatuak izango dituelarik. Azkenik, langileak zenbatzailea piztuta duen bitartean, ordu maximora heldu bezain pronto, abisua jasoko du.


## Bide-orria

Hauek dira hurrengo bertsioetan gehitu diren funtzionalitateak:

- Hitzarmena deskargatzeko aukera eman.
- Lanaldien arteko deskantsu orduak kontuan hartu
